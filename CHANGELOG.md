# Changelog

## 0.3.0

Initial PyPI release of `pyVSV`, with the `vsv` Python package and command-line interface.

- Requires Python 3.12 or later; CI checks Python 3.12, 3.13, and 3.14.
- Includes inline type information, the ontology, and the reference SBOL resource in the wheel.
- Includes tests, documentation, reference data, and curated designs in the source archive. The curated design library is supplied separately when using the installed wheel.
- Publishes through PyPI Trusted Publishing after the release tag, tests, metadata, and isolated wheel and source installs pass validation.
